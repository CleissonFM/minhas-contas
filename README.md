# Minhas Contas

App pessoal para controlar quem me deve e o que eu devo.

- Site: https://cleissonfm.github.io/minhas-contas
- Dados: Firebase (Firestore), separados por usuário (`users/{uid}/contas`).
- Regras de segurança do banco: `firestore.rules`.
- Configuração do projeto Firebase: `firebase-config.js`.
